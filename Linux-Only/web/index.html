Make SageAttention Ready for ComfyUI

Point at your ComfyUI folder. We install SageAttention into that install’s Python—not a random system one—then run a quick GPU test so ComfyUI won’t crash or spit out black frames.

Step 1 · Locate

Choose the folder that contains main.py. On Linux, prefer a .venv beside ComfyUI (example: /home/you/ComfyUI). On Windows portable, use B:\ComfyUI_windows_portable\ComfyUI — we look for python_embeded.
